# v2.21.0 — 维护中心与自动化策略

CLI 巡检升级为统一维护中心：技能源自动更新、Agent CLI 识别、版本状态、真实安装位置与升级操作在一页完成。内置识别 Claude Code、Codex、Gemini CLI、Qwen Code、OpenCode、Pi、Aider、Open Interpreter 等常见 Agent，并为每项补上人话用途说明。

「全部远端技能源」不再只是当前批量开关。开启后，未来新增的 GitHub、npm 与 well-known 来源也会默认继承；本地路径、Marketplace 插件和本地改过的 Skill 仍不会被自动覆盖。

新增应用运行时定时维护，可选每 6、12、24 或 72 小时检查。用户可以只检查，也可以让精确识别且 PATH 对齐的 Agent CLI 自动升级；关键词猜中的未知 CLI、基础工具和 PATH 冲突副本不会进入批量升级。

维护结果会保留在界面里，显示检查来源、Agent 数量、成功更新与异常项。上一次运行若因退出中断，下次启动会自动收口状态并重新检查，不会永久卡在「运行中」。

Skill 详情新增纯本地说明提炼：优先使用精选目录和 frontmatter，缺失时从 SKILL.md / README.md 提取摘要，并识别中英文的适用场景与核心能力。详情浮层支持滚动，多工具状态自适应排列。

同时修复 npm 空包页崩溃、用户级 Applications 工具漏识别、FSEvents 启动失败后不能重试等边界问题。全部更新仍沿用原子换版、回收站、本地漂移保护和跨进程写锁。
