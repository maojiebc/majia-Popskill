# 二级页面重构：实施与验收

基线：main `8d132a544dbf3a41abdbed6d9541d132455b6715`，v2.21.0。
分支：`gpt/secondary-ui-20260905`，PR #8。对应用户已确认的 2026-09-05 二级交互重构方案。

## 页面归属

主屏保留能力矩阵、挂载、工作模式和就近操作。维护中心成为主窗口的二级页面，只有“技能来源 / Agent CLI”两个对象标签。来源清单从设置迁出，长期策略从 CLI 页迁出。返回保留主屏及维护页各自的搜索、筛选、展开与滚动位置。隐藏页面不能拦截点击或键盘焦点。

原生 Settings 场景共享同一个 AppModel，固定四组：工具、自动维护、数据与恢复、关于。工具只改变界面显示与以后安装的默认目标，不修改已有链接，不创建工具目录。系统后台任务（launchd / cron）仍是独立短任务，不能与应用运行期间的维护调度混为一谈。

## 动作约定

打开维护中心仅盘点本地安装，不扩大联网权限。搜索、状态筛选只影响显示。“检查更新”只检查当前对象、明确范围，不写入新版本。常用 CLI 查询仅白名单；全部全局 CLI 需已有授权或本次会话明确同意。会话授权不改变自动巡检范围。

“更新当前结果（N）”与其数量共用同一过滤后的安全名单。批量 CLI 仍要求精确识别、原安装渠道与 PATH 对齐；不明确的安装只允许逐项确认。新来源默认值只影响未来；“应用到现有来源…”是有数量确认的独立操作。不恢复已撤回的永久来源 ID 并集。

## 结果与可靠性

MaintenanceState 不复制 entries/globalClis 库存；只保存页面上下文、检查记录和最后一个 OperationReport。实际串行 CLI 队列不变，排队与执行分开显示，完成后保留每项结果。失败重试重新校验资格，不重做成功项。

CLI 写入前重新核对安装身份、原版本和渠道；命令完成后重新盘点同一安装的版本。只有实测达到目标才显示完成，无法确认则显示“版本待确认”。停止查看页面不取消写入。安装中禁止关闭原生 sheet，避免 staging 被提前清理。StoreFS、原子换版、备份、本地漂移保护和跨进程锁不变。

数据与恢复提供全部可搜索备份。原位置同名存在时说明原因并拒绝覆盖。“直接回滚更新”仍未实现，不能把恢复按钮改名为回滚。CLI 包管理器更新也不承诺技能目录式回滚。

## 验收

- XCTest：未来默认/现有批量策略隔离、授权范围、筛选后的批次资格、仅失败重试、队列状态、版本复核、安装关闭保护、偏好不改链接、结果持久化。
- CI：macOS 14 / Xcode 16 严格并发 release build、零编译警告、全量测试、l10n 双向一致性。发布构建管道显式 pipefail，不能被 tee 吞掉失败。
- SecondaryUISnapshotTests：真实 NSHostingView/AppKit 渲染中文和英文的来源维护、CLI 维护与四组设置；临时目录和 fixture，不接触用户安装。设置含九份备份与同名冲突。
- 用户 Mac 的实际鼠标/键盘、窗口切换与真实包管理器端到端验收：未在本轮环境执行，不能用渲染或 CI 冒充。
